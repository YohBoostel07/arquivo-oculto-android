# Arquivo Oculto

Projeto Android em Godot 4.4.1.

## Primeira meta

Gerar e validar um APK Android instalável antes de iniciar a implementação das mecânicas do jogo.

## Compilação

O GitHub Actions executa a exportação Android a cada atualização da branch `main`. O APK fica disponível no artefato **Arquivo-Oculto-APK** da execução concluída.

Pacote Android: `com.arquivoculto.game`
Arquitetura: `arm64-v8a`
